Sling Shooter: Unity Slingshot Game Template

Sling Shooter is a complete physics shooting game for Unity. Aim, pull back and release, then watch stickmen and props fly and bounce with real physics.

On the Unity Asset Store it is listed as Stickman Shooter. It ships with demo levels, level editing tools and AdMob, so you can rebrand it and publish quickly.

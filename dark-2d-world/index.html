Dark 2D World: Free Limbo-Style 2D Environment Pack for Unity

Dark 2D World is a complete kit for haunting, atmospheric 2D platformers in the style of Limbo. It includes silhouette trees, terrain and props, layered backgrounds and moody particles.

It is free on the Unity Asset Store. If you need more, the Extended Version adds a larger set of assets.

Unity Asset StoreFab Marketplaceitch.io

Includes 3 hours of free 1:1 support: setup, questions, bug fixes and exporting your build.

What's included

  • 100+ handcrafted assets
  • Background and foreground parallax (3 layers)
  • Vegetation and props: trees, bushes, spikes, crates and more
  • Ambient particles: dust and falling leaves
  • Player controller and camera system
  • Post-processing for a cinematic look
  • Runs on PC, WebGL and mobile

Frequently asked questions

Which Unity versions and render pipelines does it support?

Dark 2D World is built for Unity 6 (6000.0) or newer and works with Built-in, URP. It runs on PC, WebGL, mobile.

Where can I get it?

Dark 2D World is available on Unity Asset Store, Fab Marketplace, itch.io. Use the buttons at the top of this page.

Can I use it in a commercial game?

Yes. Assets from the Unity Asset Store come with Unity's standard EULA, which allows them in commercial games. Purchases on Fab and itch.io follow those stores' licences.

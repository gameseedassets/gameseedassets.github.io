Rope Puzzle: Unity Rope Untangle Game Template

Rope Puzzle (Twisted Ropes) is a casual untangle-the-rope game for Unity. Levels are built on a grid, so it is easy to design new puzzles and scale the difficulty.

Version 2.0 includes 40 demo levels, two game modes and power-ups. You can try the playable demo on itch.io before you buy.

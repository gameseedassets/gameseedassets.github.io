Arrow Escape: Unity Arrow Puzzle Game Template

Arrow Escape is a full grid-based arrow puzzle game for Unity. Tap an arrow and it glides off the board if its path is clear, or bounces back if something is in the way. Clear every arrow to win.

It ships with a built-in level editor: turn any pixel art into a level in one click, and every generated level is always solvable. You can also drag any arrow to reshape it by hand.

What's included

  • Grid-based arrow puzzle gameplay
  • Built-in level editor with automatic and manual generation
  • Image-to-level generator: any pixel art becomes a level
  • Generated levels are always solvable
  • 30 hand-made levels plus endless mode
  • 4 arrow designs: Arrow, Casual Snake, Pattern Snake and Pencil
  • Dark mode and light mode themes
  • Automatic camera zoom and responsive grid scaling
